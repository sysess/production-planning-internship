# MTM-1 Study

MTM-1 analysis for a 3-bend sheet metal forming operation. The study breaks down the 28-step manual and machine-assisted workflow to calculate a standard time without using a stopwatch.

## Files
- `MTM_Analysis_Template.xlsx` – Blank two-handed (LH/RH) MTM-1 template with formulas for Effective TMU, process time, and PFD allowance.
- `MTM_Analysis_Example.xlsx` – Completed 28-step analysis for the sheet metal bending process (operator and part details removed for confidentiality).

## Results Summary (Example Study)
- **Manual Time:** 252.6 TMU (9.09 sec)
- **Machine Process Time:** 24.90 sec (3 bends × 8.3 sec)
- **Net Cycle Time:** 33.99 sec
- **PFD Allowance (15%):** 5.10 sec
- **Standard Time:** 39.09 sec

## Notes
- Includes simultaneous left/right hand motion evaluation, foot pedal activation (8.5 TMU), and visual inspection (`EF × 4 = 29.2 TMU`) after each bend.
- Conversion used: `1 TMU = 0.036 sec`.
