# Production Planing Internship

Welcome to my Internship Protfolio!!! 
This repository contains a collection of the projects and analysis I completed during my internship at Leka Proje in 20-workdays. 

## --Project Overview--
Below is a summary of the key modules included in this repository. Each folder contains its own READme.md file. 

### 1. Standard Time Study & Calculation Templates
* **Goal:** To standardize operational times on creating
*   **Scope:** Conducted a comprehensive time study on the production process of a multi-part industrial shipping crate. The analysis covers various operational steps across different workstations to identify bottlenecks and establish work standards.
*   **Content:** This folder contains both a reusable, blank dynamic Excel template for standard time calculations, and a populated version containing anonymized operational data for the shipping crate.

### 2. MTM (Methods-Time Measurement) Study
*   **Goal:** To analyze and optimize manual operations using predetermined motion time systems.
*   **Content:** Detailed micro-motion analysis charts evaluating the fundamental manual motions of operators to improve workplace ergonomics, eliminate inefficiencies, and calculate standard times for specific manual tasks.

### 3. Facility Layout & Forklift Route Optimization
*   **Goal:** To eliminate material handling bottlenecks and reduce the travel distance of forklifts on the production floor.
*   **Solution:** Analyzed the existing layout and proposed a new, optimized design. By redistributing the deburring tables across the center and lower columns instead of clustering them at the top, the new layout creates a much more efficient workflow.
*   **Content:** PNG/PDF files of the existing layout, the proposed alternative layout, and the optimized forklift routing plan.

### 4. Machine Constraint Analysis
*   **Goal:** To evaluate the capacity and operational limits of the production machinery.
*   **Content:** Workflow analyses and data sets highlighting machine constraints and capacity utilization.

### 5. Sensitivity Analysis
*   **Goal:** To test the robustness of the proposed models against varying production scenarios, such as changes in demand or capacity drops.
